# dataviz

Data visualization prototypes.

## pyconnectedness-explorer

An interactive explorer for [PyConnectedness](https://github.com/zstoi/PyConnectedness), showing
how shocks travel between 20 stock markets week by week — network, pair matrix, timeline and
ranking, all linked to one scrubber. Built as a design prototype, not the library's planned
browser interface.

See [`pyconnectedness-explorer/README.md`](pyconnectedness-explorer/README.md) to run it.
